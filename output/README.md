## 📁 Danh sách Tài liệu & Kết quả đầu ra

### 1. 🖥️ Slide Trình chiếu (Presentation Slides)
- **Tên file:** `cashless_pilot_slides.html`
- **Định dạng:** Interactive Web Application (HTML5 / CSS3 / Vanilla JS)
- **Thiết kế:** Giao diện Fintech Dark Mode hiện đại, tối ưu 2 cột trang đầu, tích hợp bản đồ Haiti 3D Vector và loa Soundbox thực tế, hiệu ứng chuyển slide 3D mượt mà.
- **Hướng dẫn trình chiếu:** 
  - Click đúp để mở trực tiếp trên trình duyệt Chrome/Edge/Safari.
  - Sử dụng phím **mũi tên trái/phải (`←` / `→`)** hoặc phím **Space** để chuyển slide.
  - Click nút **Fullscreen** ở góc trên cùng bên phải để bật chế độ toàn màn hình trình chiếu.
  - *Xuất sang PDF/PPTX:* Nhấn `Ctrl + P` trên trình duyệt -> Chọn "Save as PDF" (Lưu dưới dạng PDF) -> "Layout: Landscape" (Khổ ngang) -> Lưu.

### 2. 📝 Báo cáo Đề xuất (Strategic Proposal Report)
- **Tên file:** `Bao_Cao_De_Xuat_Thi_Diem_Chuyen_Dich_So.html`
- **Định dạng:** Print-friendly Web Page (Chuẩn in ấn A4)
- **Nội dung:** Báo cáo chi tiết dạng tờ trình gửi Tổng Giám đốc, phân tích sâu bối cảnh, mô hình kỹ thuật loa Soundbox, quy trình eKYC, cơ chế kích cầu và lộ trình go-live.
- **Hướng dẫn in ấn / Xuất PDF:**
  - Mở file bằng trình duyệt Chrome/Edge.
  - Nhấn tổ hợp phím **`Ctrl + P`** (hoặc `Cmd + P` trên Mac).
  - Chọn máy in là **Save as PDF** (Lưu dưới dạng PDF).
  - Cấu hình: **Khổ giấy A4**, **Khổ dọc (Portrait)**, chọn **In cả màu nền (Background graphics)** để giữ lại định dạng thiết kế đẹp nhất.
