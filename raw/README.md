# 📥 raw/ — Thư mục Nguồn Thô

> **⛔ BẤT BIẾN:** Antigravity KHÔNG được sửa, di chuyển, hoặc xóa bất kỳ file nào trong thư mục này.

---

## Cách sử dụng

Thả bất kỳ tài liệu thô nào vào đây:

| Loại nguồn | Cách lưu | Tên file gợi ý |
|---|---|---|
| Bài web | Obsidian Web Clipper / MarkDownload | `YYYY-MM-DD-tieu-de-bai.md` |
| Suy nghĩ nhanh | Superwhisper → paste trực tiếp | `YYYY-MM-DD-voice-note.md` |
| PDF (extract text) | Copy text từ PDF | `YYYY-MM-DD-ten-pdf.md` |
| Tweet / Thread | MarkDownload | `YYYY-MM-DD-tweet-topic.md` |
| Ghi chú cuộc họp | Ghi trực tiếp | `YYYY-MM-DD-meeting-topic.md` |
| Lịch sử ChatGPT | Python export script | `chatgpt-export-YYYY-MM-DD.md` |

---

## Quy ước đặt tên file

```
YYYY-MM-DD-[nguồn]-[chủ-đề-ngắn].md
```

Ví dụ:
- `2026-06-14-web-karpathy-llm-wiki.md`
- `2026-06-14-voice-ý-tưởng-sản-phẩm.md`
- `2026-06-14-meeting-review-q2.md`

---

## Sau khi thả file vào đây

Ra lệnh cho Antigravity:
```
Ingest tất cả file mới trong raw/
```
hoặc:
```
Ingest raw/[tên-file].md
```
